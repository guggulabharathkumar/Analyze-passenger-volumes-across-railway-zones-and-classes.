# 🚆 Analyze Passenger Volumes Across Railway Zones and Classes

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA) and Visualization of Railway Passenger Volumes** across different railway zones, passenger classes, and years.

The project uses Python-based data analysis techniques to clean, explore, process, and visualize railway passenger data. The analysis helps understand passenger movement patterns and compare passenger volumes across different railway zones and classes.

The project was developed as part of the **Exploratory Data Analysis and Visualization (22AC31N)** course at **Chaitanya Bharathi Institute of Technology (CBIT), Hyderabad**.

---

## 🎯 Objectives

* Analyze total passenger volumes.
* Compare passenger records across different railway zones.
* Analyze passenger volumes across different passenger classes.
* Clean and preprocess the railway passenger dataset.
* Identify and handle missing passenger-count values.
* Analyze passenger volume trends across railway zones and years.
* Create meaningful visualizations using Python libraries.
* Extract useful statistical information and insights from the dataset.

---

## ❓ Problem Statement

Railway passenger datasets contain passenger volumes across different railway zones, passenger classes, and years. Raw passenger records can be difficult to interpret without systematic analysis.

This project addresses questions such as:

* What is the total passenger volume?
* How can passenger records be filtered by class and zone?
* How can missing passenger-count values be identified and handled?
* How does passenger volume vary across railway zones?
* How does passenger volume change across different years?

Exploratory data analysis and visualization are used to convert the raw data into meaningful statistical and visual information.

---

## 📊 Dataset

### Dataset Name

**CEP-25 Railway Passenger Statistics Enhanced Dataset**

### Dataset Source

**data.gov.in – Railway Passenger Statistics**

The dataset contains railway passenger records organized by zones and classes, along with fare and occupancy-related information.

### Important Columns

| Column          | Description                  |
| --------------- | ---------------------------- |
| `Year`          | Year of the passenger record |
| `Zone`          | Railway zone                 |
| `Class`         | Passenger class              |
| `Passengers`    | Number of passengers         |
| `Avg_Fare_Rs`   | Average fare in rupees       |
| `Occupancy_Pct` | Occupancy percentage         |
| `Revenue_Rs`    | Revenue in rupees            |
